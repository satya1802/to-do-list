<!-- sdlc:auto:start overview -->
This repository is a frontend-only prototype generated by the Quorq AI SDLC platform: a Vite + React (v22) single-page app living entirely under frontend/. It renders a set of approved screens against seeded sample data with no live backend wired in yet; frontend/src/lib/api.ts is the prepared integration seam (base URL, bearer auth, session token helpers) for when a real API is connected. Styling uses Tailwind CSS via the Vite plugin, routing uses react-router-dom, and the toolchain is TypeScript + ESLint + Prettier with Vitest for unit tests and Playwright for e2e tests.

<!-- sdlc:auto:start conventions -->
- Path alias '@' maps to frontend/src (configured in both vite.config.ts and tsconfig.json).
- API integration is isolated in src/lib/api.ts: API_BASE_URL and API_SECRET_KEY are read from Vite env vars (VITE_API_BASE_URL, VITE_API_SECRET_KEY) with local-dev fallbacks.
- apiFetch() attaches a bearer token (session token if present via localStorage, else the shared API secret) as Authorization header on every call.
- Session token is persisted via getSessionToken/setSessionToken/clearSessionToken wrapping localStorage with try/catch for unavailable storage.
- Component/unit tests are scoped to src/**/*.{test,spec}.{ts,tsx} and run under jsdom with Vitest; e2e specs live separately in e2e/ and are run only by Playwright.
- Styling via Tailwind CSS (@tailwindcss/vite plugin) and CSS variables in index.css.
- ESLint + Prettier (eslint-config-prettier) enforce a single formatting/lint standard; lint is treated as a required gate.
<!-- sdlc:auto:end conventions -->

<!-- sdlc:auto:start troubleshooting -->
| Problem | Solution |
|---|---|
| npm run build succeeds but tsc fails later / deployment breaks on type errors. | Run npm run typecheck (tsc --noEmit) separately before shipping, since build does not type-check. |
| Playwright e2e tests fail immediately with a missing browser error. | Run npm run test:e2e:install once to fetch Chromium before npm run test:e2e. |
| Screens appear to call a backend but nothing happens / requests go to http://localhost:8000. | This is a frontend-only prototype on seeded data; src/lib/api.ts is the seam for wiring a real API later, not an active integration yet. |
| Vitest run accidentally picks up Playwright spec files and fails on missing fixtures. | Vitest is scoped via vite.config.ts test.include to src/**/*.{test,spec}.ts(x) only; keep e2e specs in e2e/, not under src/. |
<!-- sdlc:auto:end troubleshooting -->
